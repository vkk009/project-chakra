# Jarvis AI Assistant for Deaf and Mute People

## Overview

This project is a Python-based AI assistant designed for deaf and mute people.

Features include:
- Speech to text
- Text to speech
- Sign language detection
- Emergency alerts
- AI chatbot

---

## Technologies Used

- Python
- OpenCV
- MediaPipe
- TensorFlow
- SpeechRecognition
- Tkinter
